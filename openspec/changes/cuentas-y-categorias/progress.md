# Progreso: cuentas-y-categorias
- Siguiente: 3.5 RED — `src/app/(privado)/cuentas/cuentas.test.tsx`, test "Pantalla de cuentas sin cuentas muestra el estado vacío" (el botón enfoca el campo nombre).
- Decisiones: cada ciclo RED/GREEN/REFACTOR va en un commit con la suite en verde; el RED se registra en el cuerpo del commit. Las mutaciones se hacen con `docker exec cuadre-db psql` sobre `cuadre_test` y se restauran antes del commit. Tests de aislamiento entre usuarios: el segundo usuario se crea con `crearUsuarioSinCategorias` (`src/test/bd/usuarios.ts`), sin seed. Pantalla de cuentas: `ul` con `aria-label="Cuentas"`; los tests de la lista usan `within` para no chocar con las opciones del selector.
- Discrepancias: el pre-commit ejecuta la suite completa, así que un RED no puede commitearse solo. El hook bloquea escribir archivos nuevos en `prisma/migrations/`. Las mutaciones que quitan `usuario_id` del índice rompen también el registro de los tests de 2.28, que usan seed.
