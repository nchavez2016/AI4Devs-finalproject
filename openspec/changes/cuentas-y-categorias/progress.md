# Progreso: cuentas-y-categorias
- Siguiente: 3.8 RED — `src/app/(privado)/cuentas/cuentas.test.tsx`, test "Formulario de cuenta muestra el error junto a cada campo", y en `src/server/cuentas/acciones.test.ts` el test de apoyo "crearCuentaAccion devuelve los errores por campo del caso de uso".
- Decisiones: cada ciclo RED/GREEN/REFACTOR va en un commit con la suite en verde; el RED se registra en el cuerpo del commit. Las mutaciones se hacen con `docker exec cuadre-db psql` sobre `cuadre_test` y se restauran antes del commit. Tests de aislamiento entre usuarios: el segundo usuario se crea con `crearUsuarioSinCategorias` (`src/test/bd/usuarios.ts`), sin seed. Pantalla de cuentas: `ul` con `aria-label="Cuentas"` solo si hay cuentas; el estado vacío enfoca el campo `nombre` a través de la ref del `form` (`formularioRef`).
- Discrepancias: el pre-commit ejecuta la suite completa, así que un RED no puede commitearse solo. El hook bloquea escribir archivos nuevos en `prisma/migrations/`. Las mutaciones que quitan `usuario_id` del índice rompen también el registro de los tests de 2.28, que usan seed.
