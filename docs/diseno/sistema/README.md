# Sistema de diseño — Cuadre

Índice del sistema de diseño del MVP, un archivo por tema. Las referencias cruzadas citan el
archivo y la sección ("tokens.md, 3.4"). Material de partida: `../brief.md` y `../propuestas.md`.

| Archivo | Contiene | Léelo cuando... |
|---|---|---|
| [decisiones.md](decisiones.md) | 1–2. Análisis de las tres propuestas y las dos direcciones (recomendada y alternativa) | quieras entender por qué se descartó o conservó una idea |
| [tokens.md](tokens.md) | 3. Reglas de tokens, implementación en Tailwind 4/shadcn/ui, catálogo completo, contraste calculado y temas futuros | vayas a definir o usar un color, tamaño, radio, sombra o duración |
| [tipografia-y-espacio.md](tipografia-y-espacio.md) | 4–5. Familias, escala tipográfica, cifras tabulares, espaciado, radios, bordes y elevación | vayas a maquetar una pantalla o elegir un tamaño de texto |
| [movimiento.md](movimiento.md) | 6. Qué se anima, duraciones, curvas y movimiento reducido | vayas a animar algo o revisar `prefers-reduced-motion` |
| [componentes.md](componentes.md) | 7. Botón, campo de formulario, tarjeta, lista/tabla de movimientos e Importe | vayas a construir o revisar uno de estos componentes |
| [visualizacion.md](visualizacion.md) | 8. Qué gráfico exige el MVP, su tipo, tokens, ejes, estados, accesibilidad e implementación con Recharts | vayas a construir el gráfico de categorías de gasto u otro futuro |
| [estados.md](estados.md) | 9. Patrones de vacío, carga, error y éxito | vayas a diseñar los cuatro estados de una pantalla nueva |
| [checklist.md](checklist.md) | 10. Checklist de revisión UX para cada pantalla nueva | vayas a dar por terminada una pantalla |

Sustituye a `docs/diseno/sistema-de-diseno.md` (un único archivo, ya retirado).
